# Data Lab Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#102033` | Headings and metric labels |
| Slate | `#475569` | Supporting copy |
| Data blue | `#0284c7` | Links, pipelines, and primary metrics |
| Lab teal | `#0f766e` | Datasets, freshness, and valid samples |
| Experiment violet | `#7c3aed` | Runs, variants, and candidate models |
| Warning amber | `#ca8a04` | Data drift and stale inputs |
| Grid | `#dbeafe` | Tables, rails, and separators |

## Guidance

- Tables should carry the theme; avoid long prose for metrics.
- Always pair benchmark numbers with split, baseline, and decision.
- Use animated dividers for pipeline flow, not every section break.
