# AI Neural Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#111827` | Dense model names, metric labels, and headings |
| Signal blue | `#2563eb` | Primary links, model paths, and inference flow |
| Neural violet | `#7c3aed` | Experiments, variants, embeddings, and latent-space accents |
| Core cyan | `#06b6d4` | Data movement, eval traces, and active signals |
| Success green | `#16a34a` | Passing evaluations and promoted releases |
| Warning amber | `#ca8a04` | Drift, caveats, and reproducibility warnings |
| Grid | `#dbeafe` | Tables, diagrams, separators, and low-emphasis structure |

## Guidance

- Use blue for the main workflow and violet for research or experiment branches.
- Put metrics in tables with dataset, split, baseline, and current result.
- Keep animated neural assets near model, benchmark, or pipeline sections.
