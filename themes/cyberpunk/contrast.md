# Cyberpunk Contrast

| Foreground | Background | Use |
| --- | --- | --- |
| `#05070d` | `#0b1020` | Panel accents on primary text/canvas areas. |
| `#05070d` | `#172033` | Grid accents on primary text/canvas areas. |
| `#05070d` | `#22d3ee` | Cyan accents on primary text/canvas areas. |
| `#05070d` | `#38bdf8` | Blue accents on primary text/canvas areas. |
| `#05070d` | `#34d399` | Primary body text on light or neutral canvas. |

## Rules

- Keep body text on high-contrast neutral colors.
- Test dark theme snippets on GitHub's README renderer.
- Do not use low-contrast accent-on-accent pairs for tables.
