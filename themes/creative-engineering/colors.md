# Creative Engineering Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#111827` | Technical headings |
| Blue | `#2563eb` | Main links |
| Cyan | `#06b6d4` | Motion and systems |
| Violet | `#7c3aed` | Creative highlights |
| Pink | `#db2777` | Expressive accents |
| Green | `#16a34a` | Working demos |
| Line | `#dbeafe` | Structure |

## Guidance

- Keep the primary accent consistent across links, badges, and section markers.
- Reserve warning and danger colors for real status meaning.
- Use neutral line colors for dense tables so content stays readable.
