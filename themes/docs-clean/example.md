# Docs Clean Theme

[![Docs clean header](https://raw.githubusercontent.com/HiradEmami/readme-ux-kit/master/assets/headers/static/header_split_line.svg)](https://github.com/HiradEmami/readme-ux-kit)

> A reference-first README theme for documentation portals, SDKs, API packages, and repositories where the fastest path to the right page matters most.

## Start Here

| Need | Go to | Outcome |
| --- | --- | --- |
| Install the package | Quick start | Working local setup |
| Learn the API | Reference | Methods, inputs, and outputs |
| Copy examples | Recipes | Task-focused snippets |
| Debug behavior | Troubleshooting | Known causes and fixes |

[![Docs divider](https://raw.githubusercontent.com/HiradEmami/readme-ux-kit/master/assets/dividers/static/divider_minimal_clean.svg)](https://github.com/HiradEmami/readme-ux-kit)

## Reference Layout

| Section | Content rule |
| --- | --- |
| Overview | One paragraph, one table, one next action |
| Quick start | Commands first, explanation second |
| Concepts | Use short definitions and link to deeper docs |
| API | Keep signatures, parameters, returns, and examples together |
| Support | Route issues, discussions, and security reports clearly |

## Recommended Components

| Component | Why it fits |
| --- | --- |
| [`components/layout/faq.md`](../../components/layout/faq.md) | Handles common docs questions without long prose. |
| [`components/interactive/tabs.md`](../../components/interactive/tabs.md) | Organizes language or framework variants. |
| [`components/interactive/expand-collapse.md`](../../components/interactive/expand-collapse.md) | Keeps advanced examples available but collapsed. |
| [`components/layout/hero-sections.md`](../../components/layout/hero-sections.md) | Provides a clean top section without marketing weight. |
