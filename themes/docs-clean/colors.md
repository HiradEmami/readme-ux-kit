# Docs Clean Colors

| Token | Hex | Use |
| --- | --- | --- |
| Text | `#1f2937` | Primary body copy |
| Muted | `#667085` | Captions and helper copy |
| Link | `#0f62fe` | Navigation and API references |
| Success | `#2f855a` | Stable examples and supported versions |
| Note | `#7c3aed` | Concept callouts and tips |
| Rule | `#e5e7eb` | Table borders and section separators |
| Canvas | `#ffffff` | Default README background |

## Guidance

- Use whitespace, tables, and short links as the main visual system.
- Keep animation rare; docs readers usually need speed and clarity.
- Avoid dense hero visuals in API-heavy projects.
