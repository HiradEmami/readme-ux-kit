# Docs Clean Contrast

| Foreground | Background | Use |
| --- | --- | --- |
| `#1f2937` | `#667085` | Muted accents on primary text/canvas areas. |
| `#1f2937` | `#0f62fe` | Link accents on primary text/canvas areas. |
| `#1f2937` | `#2f855a` | Success accents on primary text/canvas areas. |
| `#1f2937` | `#7c3aed` | Note accents on primary text/canvas areas. |
| `#1f2937` | `#ffffff` | Primary body text on light or neutral canvas. |

## Rules

- Keep body text on high-contrast neutral colors.
- Test dark theme snippets on GitHub's README renderer.
- Do not use low-contrast accent-on-accent pairs for tables.
