# Academic Lab Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#1f2937` | Research headings |
| Blue | `#1d4ed8` | Links and artifacts |
| Teal | `#0f766e` | Datasets |
| Violet | `#6d28d9` | Experiments |
| Amber | `#b45309` | Limitations |
| Line | `#d1d5db` | Tables |
| Canvas | `#fafafa` | Reading surface |

## Guidance

- Keep the primary accent consistent across links, badges, and section markers.
- Reserve warning and danger colors for real status meaning.
- Use neutral line colors for dense tables so content stays readable.
