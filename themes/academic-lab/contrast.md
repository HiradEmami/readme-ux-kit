# Academic Lab Contrast

| Foreground | Background | Use |
| --- | --- | --- |
| `#1f2937` | `#1d4ed8` | Blue accents on primary text/canvas areas. |
| `#1f2937` | `#0f766e` | Teal accents on primary text/canvas areas. |
| `#1f2937` | `#6d28d9` | Violet accents on primary text/canvas areas. |
| `#1f2937` | `#b45309` | Amber accents on primary text/canvas areas. |
| `#1f2937` | `#fafafa` | Primary body text on light or neutral canvas. |

## Rules

- Keep body text on high-contrast neutral colors.
- Test dark theme snippets on GitHub's README renderer.
- Do not use low-contrast accent-on-accent pairs for tables.
