# Reliability Ops Theme

> Calm, measurable, incident-ready.

Use this theme for sre, uptime, incident, and production readiness readmes. Keep the tone operational, factual, no-drama.

## Project Signal

| Signal | Recommendation |
| --- | --- |
| Best for | SRE, uptime, incident, and production readiness READMEs |
| Motion | `low` |
| Density | `dense` |
| Voice | Operational, factual, no-drama |
