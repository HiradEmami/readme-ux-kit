# Reliability Ops Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#101828` | Operational headings |
| Blue | `#2563eb` | Primary status |
| Green | `#16a34a` | Healthy paths |
| Amber | `#d97706` | Review states |
| Red | `#dc2626` | Incidents |
| Line | `#cbd5e1` | Rules |
| Canvas | `#f8fafc` | Panels |

## Guidance

- Keep the primary accent consistent across links, badges, and section markers.
- Reserve warning and danger colors for real status meaning.
- Use neutral line colors for dense tables so content stays readable.
