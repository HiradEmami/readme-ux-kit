# Reliability Ops Voice

## Tone

Operational, factual, no-drama.

## Heading Style

- Prefer concrete nouns over slogans.
- Use short section names that match reader intent.
- Put the promise in the first paragraph, not only in a decorative header.

## Preferred Wording

- "Install", "Run", "Verify", "Configure", "Support", "Status".
- "Known limitations" when a boundary matters.
- "Recommended" only when the project can defend the recommendation.

## Avoid

- Fake production claims.
- Vague phrases such as "next-generation" without proof.
- Badge walls that replace a real quick start.
- Long marketing copy before users can run the project.
