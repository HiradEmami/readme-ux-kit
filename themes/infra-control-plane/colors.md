# Infra Control Plane Colors

| Token | Hex | Use |
| --- | --- | --- |
| Base | `#0f172a` | Control plane background |
| Blue | `#2563eb` | Primary links |
| Cyan | `#0891b2` | Network paths |
| Green | `#16a34a` | Healthy deployments |
| Amber | `#d97706` | Change windows |
| Red | `#dc2626` | Risk |
| Line | `#334155` | Topology edges |

## Guidance

- Keep the primary accent consistent across links, badges, and section markers.
- Reserve warning and danger colors for real status meaning.
- Use neutral line colors for dense tables so content stays readable.
