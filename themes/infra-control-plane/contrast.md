# Infra Control Plane Contrast

| Foreground | Background | Use |
| --- | --- | --- |
| `#0f172a` | `#2563eb` | Blue accents on primary text/canvas areas. |
| `#0f172a` | `#0891b2` | Cyan accents on primary text/canvas areas. |
| `#0f172a` | `#16a34a` | Green accents on primary text/canvas areas. |
| `#0f172a` | `#d97706` | Amber accents on primary text/canvas areas. |
| `#0f172a` | `#334155` | Primary body text on light or neutral canvas. |

## Rules

- Keep body text on high-contrast neutral colors.
- Test dark theme snippets on GitHub's README renderer.
- Do not use low-contrast accent-on-accent pairs for tables.
