# Developer Platform Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#111827` | API names |
| Blue | `#2563eb` | Links and commands |
| Cyan | `#06b6d4` | Integrations |
| Green | `#16a34a` | Supported flows |
| Violet | `#7c3aed` | Extensions |
| Line | `#dbeafe` | Tables |
| Canvas | `#f8fafc` | Docs surface |

## Guidance

- Keep the primary accent consistent across links, badges, and section markers.
- Reserve warning and danger colors for real status meaning.
- Use neutral line colors for dense tables so content stays readable.
