# Open Governance Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#24292f` | Governance headings |
| Blue | `#0969da` | Links |
| Green | `#1a7f37` | Accepted proposals |
| Purple | `#8250df` | Discussion |
| Amber | `#bf8700` | Review |
| Border | `#d0d7de` | Rules |
| Canvas | `#f6f8fa` | Docs panels |

## Guidance

- Keep the primary accent consistent across links, badges, and section markers.
- Reserve warning and danger colors for real status meaning.
- Use neutral line colors for dense tables so content stays readable.
