# Open Governance Contrast

| Foreground | Background | Use |
| --- | --- | --- |
| `#24292f` | `#0969da` | Blue accents on primary text/canvas areas. |
| `#24292f` | `#1a7f37` | Green accents on primary text/canvas areas. |
| `#24292f` | `#8250df` | Purple accents on primary text/canvas areas. |
| `#24292f` | `#bf8700` | Amber accents on primary text/canvas areas. |
| `#24292f` | `#f6f8fa` | Primary body text on light or neutral canvas. |

## Rules

- Keep body text on high-contrast neutral colors.
- Test dark theme snippets on GitHub's README renderer.
- Do not use low-contrast accent-on-accent pairs for tables.
