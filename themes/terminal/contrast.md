# Terminal Contrast

| Foreground | Background | Use |
| --- | --- | --- |
| `#0f172a` | `#22c55e` | Terminal green accents on primary text/canvas areas. |
| `#0f172a` | `#38bdf8` | Command blue accents on primary text/canvas areas. |
| `#0f172a` | `#f59e0b` | Warning amber accents on primary text/canvas areas. |
| `#0f172a` | `#ef4444` | Failure red accents on primary text/canvas areas. |
| `#0f172a` | `#1e293b` | Primary body text on light or neutral canvas. |

## Rules

- Keep body text on high-contrast neutral colors.
- Test dark theme snippets on GitHub's README renderer.
- Do not use low-contrast accent-on-accent pairs for tables.
