# Privacy Compliance Colors

| Token | Hex | Use |
| --- | --- | --- |
| Base | `#0b1020` | Trust background |
| Text | `#e5edf7` | Readable dark text |
| Blue | `#38bdf8` | Policy links |
| Green | `#22c55e` | Compliant state |
| Amber | `#f59e0b` | Review needed |
| Red | `#ef4444` | Risk |
| Boundary | `#334155` | Data edges |

## Guidance

- Keep the primary accent consistent across links, badges, and section markers.
- Reserve warning and danger colors for real status meaning.
- Use neutral line colors for dense tables so content stays readable.
