# Open Source Classic Colors

| Token | Hex | Use |
| --- | --- | --- |
| Text | `#24292f` | GitHub-native body copy |
| Muted | `#57606a` | Maintainer notes and metadata |
| Link | `#0969da` | Standard GitHub link color |
| Success | `#1a7f37` | Stable, passing, supported |
| Sponsor | `#bf3989` | Community and funding accents |
| Border | `#d0d7de` | Tables and separators |
| Canvas | `#f6f8fa` | Code-adjacent neutral panels |

## Guidance

- Keep the theme familiar; do not over-style community README content.
- Put contribution paths near the top for projects that want help.
- Use one friendly accent for sponsorship or community sections.
