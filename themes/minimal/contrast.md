# Minimal Contrast

| Foreground | Background | Use |
| --- | --- | --- |
| `#0f172a` | `#475569` | Slate accents on primary text/canvas areas. |
| `#0f172a` | `#f8fafc` | Mist accents on primary text/canvas areas. |
| `#0f172a` | `#cbd5e1` | Line accents on primary text/canvas areas. |
| `#0f172a` | `#0f766e` | Teal accents on primary text/canvas areas. |
| `#0f172a` | `#7c3aed` | Primary body text on light or neutral canvas. |

## Rules

- Keep body text on high-contrast neutral colors.
- Test dark theme snippets on GitHub's README renderer.
- Do not use low-contrast accent-on-accent pairs for tables.
