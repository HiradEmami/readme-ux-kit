# Minimal Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#0f172a` | Primary headings and compact labels |
| Slate | `#475569` | Supporting copy and secondary table text |
| Mist | `#f8fafc` | Light backgrounds and calm separators |
| Line | `#cbd5e1` | Rules, table borders, and subtle structure |
| Teal | `#0f766e` | Primary success and trusted action accents |
| Blue | `#2563eb` | Links, install paths, and documentation references |
| Violet | `#7c3aed` | Optional highlight for releases or examples |

## Guidance

- Prefer one accent color per README section.
- Use static assets first; add motion only when it improves orientation.
- Keep tables narrow and factual so the theme stays quiet.
