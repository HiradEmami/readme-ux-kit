# Themes

Theme examples combine assets, layout choices, tone, tokens, contrast, and component pairings so a README feels consistent from top to bottom.

| Theme | Best for | Primary feel |
| --- | --- | --- |
| [Minimal](./minimal/example.md) | Libraries, SDKs, and polished utilities | Quiet, restrained, low-noise. |
| [Terminal](./terminal/example.md) | CLI tools and automation workflows | Command-first, practical, direct. |
| [AI Neural](./ai-neural/example.md) | ML, AI, data, and research projects | Technical, model-centric, intelligent. |
| [Cyberpunk](./cyberpunk/example.md) | Security, DevOps, infrastructure, and high-energy tools | Dark, neon, operational. |
| [Enterprise](./enterprise/example.md) | SaaS platforms, internal tools, and production systems | Trustworthy, measured, governance-ready. |
| [Docs Clean](./docs-clean/example.md) | Documentation sites, SDK guides, and API references | Bright, scannable, reference-first. |
| [Security Ops](./security-ops/example.md) | Security tools, scanners, policies, and incident workflows | Alert-aware, precise, operational. |
| [Data Lab](./data-lab/example.md) | Analytics, notebooks, pipelines, and research datasets | Evidence-led, experimental, structured. |
| [Open Source Classic](./open-source-classic/example.md) | Community libraries, frameworks, and starter kits | Familiar, welcoming, contributor-friendly. |
| [Reliability Ops](./reliability-ops/example.md) | SRE, uptime, incident, and production readiness READMEs | Calm, measurable, incident-ready. |
| [Founder Product](./founder-product/example.md) | Launch pages, early products, demos, and business-facing projects | Confident, concise, market-aware. |

| [Developer Platform](./developer-platform/example.md) | SDKs, APIs, CLIs, integrations, and platform products | Technical, navigable, extensible. |

## How to Use a Theme

1. Pick a base template from [`templates/`](../templates/).
2. Copy the theme header, divider, and recommended asset choices.
3. Keep one visual language across the README.
4. Use the theme's `tokens.json`, `usage.md`, `voice.md`, and `contrast.md` before adding custom colors.
5. Avoid mixing too many animated assets in dense documentation.
