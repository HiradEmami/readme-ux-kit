# Security Ops Contrast

| Foreground | Background | Use |
| --- | --- | --- |
| `#0b1020` | `#e5edf7` | Text accents on primary text/canvas areas. |
| `#0b1020` | `#38bdf8` | Scan blue accents on primary text/canvas areas. |
| `#0b1020` | `#22c55e` | Trust green accents on primary text/canvas areas. |
| `#0b1020` | `#ef4444` | Alert red accents on primary text/canvas areas. |
| `#0b1020` | `#334155` | Primary body text on light or neutral canvas. |

## Rules

- Keep body text on high-contrast neutral colors.
- Test dark theme snippets on GitHub's README renderer.
- Do not use low-contrast accent-on-accent pairs for tables.
