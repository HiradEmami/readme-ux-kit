# Security Ops Colors

| Token | Hex | Use |
| --- | --- | --- |
| Base | `#0b1020` | Dark preview background |
| Text | `#e5edf7` | Dark-mode readable copy |
| Scan blue | `#38bdf8` | Detection, scanning, and telemetry |
| Trust green | `#22c55e` | Verified and remediated states |
| Alert red | `#ef4444` | Critical findings only |
| Review amber | `#f59e0b` | Review, pending, and warning states |
| Boundary | `#334155` | Tables and separators |

## Guidance

- Reserve red for true risk; overusing it makes security docs harder to scan.
- Pair every scary visual with concrete controls, checks, or evidence.
- Keep disclosure and permission guidance close to installation instructions.
