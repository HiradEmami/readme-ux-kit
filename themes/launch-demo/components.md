# Launch Demo Components

## Best Pairings

| Component | Why it fits |
| --- | --- |
| [`Start Here`](../../components/navigation/start-here.md) | Routes readers before the README gets dense. |
| [`Feature grids`](../../components/layout/feature-grids.md) | Summarizes capabilities without long prose. |
| [`System badges`](../../components/badges/system-badges.md) | Keeps factual signals compact. |
| [`Testing strategy`](../../components/quality/testing-strategy.md) | Makes quality expectations explicit. |
| [`Support policy`](../../components/trust/support-policy.md) | Clarifies support boundaries. |

## Use Sparingly

- Animated badges when the README is already visually busy.
- Long collapsible sections above the quick start.
- Multiple progress bars that measure unrelated concepts.
