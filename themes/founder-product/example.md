# Founder Product Theme

> Confident, concise, market-aware.

Use this theme for launch pages, early products, demos, and business-facing projects. Keep the tone outcome-led, concrete, credible.

## Project Signal

| Signal | Recommendation |
| --- | --- |
| Best for | Launch pages, early products, demos, and business-facing projects |
| Motion | `moderate` |
| Density | `medium` |
| Voice | Outcome-led, concrete, credible |
