# Founder Product Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#111827` | Product claims |
| Blue | `#2563eb` | Primary actions |
| Teal | `#0f766e` | Trust signals |
| Violet | `#7c3aed` | Launch highlights |
| Amber | `#d97706` | Beta notes |
| Line | `#d1d5db` | Structure |
| Canvas | `#ffffff` | Clean surface |

## Guidance

- Keep the primary accent consistent across links, badges, and section markers.
- Reserve warning and danger colors for real status meaning.
- Use neutral line colors for dense tables so content stays readable.
