# Portfolio Premium Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#111827` | Profile headings |
| Slate | `#475569` | Context |
| Blue | `#2563eb` | Links |
| Violet | `#7c3aed` | Highlights |
| Rose | `#be185d` | Personal accent |
| Line | `#e5e7eb` | Sections |
| Canvas | `#ffffff` | Clean backdrop |

## Guidance

- Keep the primary accent consistent across links, badges, and section markers.
- Reserve warning and danger colors for real status meaning.
- Use neutral line colors for dense tables so content stays readable.
