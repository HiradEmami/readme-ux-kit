| Foreground | Background | Use |
| --- | --- | --- |
| `#111827` | `#475569` | Slate accents on primary text/canvas areas. |
| `#111827` | `#2563eb` | Blue accents on primary text/canvas areas. |
| `#111827` | `#7c3aed` | Violet accents on primary text/canvas areas. |
| `#111827` | `#be185d` | Rose accents on primary text/canvas areas. |
| `#111827` | `#ffffff` | Primary body text on light or neutral canvas. |

## Rules

- Keep body text on high-contrast neutral colors.
- Test dark theme snippets on GitHub's README renderer.
- Do not use low-contrast accent-on-accent pairs for tables.
