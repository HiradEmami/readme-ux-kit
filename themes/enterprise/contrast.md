# Enterprise Contrast

| Foreground | Background | Use |
| --- | --- | --- |
| `#172033` | `#4b5b73` | Steel accents on primary text/canvas areas. |
| `#172033` | `#2563eb` | Trust blue accents on primary text/canvas areas. |
| `#172033` | `#16a34a` | Signal green accents on primary text/canvas areas. |
| `#172033` | `#d97706` | Review amber accents on primary text/canvas areas. |
| `#172033` | `#f8fafc` | Primary body text on light or neutral canvas. |

## Rules

- Keep body text on high-contrast neutral colors.
- Test dark theme snippets on GitHub's README renderer.
- Do not use low-contrast accent-on-accent pairs for tables.
