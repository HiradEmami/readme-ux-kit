# Enterprise Colors

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#172033` | Main headings and table labels |
| Steel | `#4b5b73` | Secondary copy and metadata |
| Trust blue | `#2563eb` | Primary links and stable status |
| Signal green | `#16a34a` | Passing checks and support commitments |
| Review amber | `#d97706` | Review, candidate, and warning states |
| Panel line | `#d7dee8` | Dividers and table rules |
| Canvas | `#f8fafc` | Light README preview backgrounds |

## Guidance

- Keep the top visual calm; one header plus one hero visual is enough.
- Prefer blue and green status accents over heavy neon colors.
- Use amber only for review or action-required states.
