# Templates

Ready-to-copy README foundations for common project types. Start with the closest match, then layer in assets, themes, and components.

| Template | Maturity | Best for | Notes |
| --- | --- | --- | --- |
| [Minimal](./minimal.md) | `stable` | Small tools, utilities, and focused repos | Lean structure with quick start, config, roadmap, and status. |
| [Backend service](./backend-service.md) | `stable` | APIs and production services | Includes architecture, API, operations, deployment, and runbook sections. |
| [ML project](./ml-project.md) | `draft` | Model training, evaluation, and inference repos | Includes data, training, evaluation, model card, and experiment log sections. |
| [Open-source library](./open-source-lib.md) | `stable` | Published packages and reusable libraries | Includes install, API, examples, compatibility, testing, and security sections. |
| [Research project](./research-project.md) | `draft` | Papers, experiments, and reproducibility repos | Includes abstract, contributions, results, reproduction, limitations, and citation. |

## Maturity

| Marker | Meaning |
| --- | --- |
| `stable` | Ready for broad reuse after placeholder replacement. |
| `draft` | Useful and complete, but likely needs closer project-specific editing. |
| `experimental` | Reserved for future templates with high-expression or advanced patterns. |

For the full maturity policy, see [Design maturity](../docs/MATURITY.md).
