## Per-Asset Cryptographic Fields

Every asset record in [`assets/provenance.json`](assets/provenance.json) and [`ASSET_PROVENANCE.json`](ASSET_PROVENANCE.json) includes:

- `name`: Canonical asset identifier.
- `path`: Repository-relative SVG path (`assets/<category>/...`).
- `category` and `subcategory`: Taxonomy placement.
- `origin`: `"first-party"` or `"third-party-derived"`.
- `source`: `"readme-ux-kit"` or upstream repository URL.
- `license`: SPDX/canonical license identifier (`"MIT"` or `"The Unlicense"`).
- `exists`: Boolean file-presence check.
- `byteLength`: Exact UTF-8 file size in bytes.
- `sha256`: Lowercase 64-character hexadecimal SHA-256 digest of the SVG file bytes.
