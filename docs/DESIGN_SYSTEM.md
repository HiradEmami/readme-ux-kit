# Design System

`readme-ux-kit` is organized as a README design system:

| Layer | Purpose |
| --- | --- |
| Assets | SVG visuals, icons, headers, dividers, buttons, loading states, and progress bars. |
| Components | Copy-ready Markdown sections for specific jobs. |
| Templates | Full README foundations for project types. |
| Themes | Visual, tonal, and asset direction. |
| Previews | Generated browsing pages for assets and usage snippets. |
| Generator data | Machine-readable indexes and contracts for local tools. |

Use one template, one theme, and a small component stack. Add assets only when they improve scanning or trust.
