# Component Authoring

Every component should be copy-ready and reviewable.

Required sections:

- Purpose.
- Best for.
- Maturity marker.
- Copy-ready Markdown.
- Required placeholders.
- Optional placeholders.
- Compatible themes.
- Compatible templates.
- Design rules.
- GitHub compatibility notes.
- Do not use when.
- Copy checklist.

Use factual examples and avoid claims that look like real production status unless they are placeholders.
