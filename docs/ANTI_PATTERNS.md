# README Anti-Patterns

## Badge Wall

Badges cannot replace a quick start, support policy, or examples. Keep badges factual and short.

## Animation Overload

Motion should orient the reader. Too many animated assets slow scanning and can make operational docs feel less trustworthy.

## Fake Status

Do not publish passing, stable, supported, or production-ready claims unless the project can prove them.

## Broken Local Links

Every internal link should point to a committed file, an anchor, or an intentional placeholder inside a copy block.

## Visual First, Run Last

Readers should understand what the project does and how to run it before they reach decorative content.
