# Theme System

Each theme folder should include:

- `example.md`
- `colors.md`
- `assets-map.md`
- `tokens.json`
- `usage.md`
- `voice.md`
- `components.md`
- `template-matrix.md`
- `contrast.md`
- `preview.md`

Themes define visual direction, voice, motion level, density, asset strategy, contrast rules, and recommended template/component pairings.
