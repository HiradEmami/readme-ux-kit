# Quality Bar

| Marker | Requirement |
| --- | --- |
| `stable` | Ready for broad reuse after placeholder replacement. Must have copy checklist and link-safe Markdown. |
| `draft` | Useful and complete, but needs project-specific review. |
| `experimental` | High-expression or advanced pattern that needs visual, accessibility, and compatibility review. |

Stable files must avoid unresolved accidental placeholders, broken local links, unsupported GitHub behavior, fake production claims, and unclear ownership.
