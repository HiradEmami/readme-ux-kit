# Compatibility Matrix

| Template | Strong Themes | Strong Components | Asset Families |
| --- | --- | --- | --- |
| `cli-tool` | `terminal`, `minimal`, `developer-platform` | `reference/cli-reference`, `onboarding/first-run`, `quality/testing-strategy` | headers, icons, terminal dividers |
| `backend-service` | `enterprise`, `reliability-ops`, `terminal` | `trust/support-policy`, `quality/observability`, `reference/api-reference` | file headers, status icons, progress bars |
| `ml-project` | `ai-neural`, `data-lab`, `academic-lab` | `status/ml-experiments`, `quality/testing-strategy`, `trust/provenance` | neural visuals, data icons, animated dividers |
| `open-source-lib` | `open-source-classic`, `docs-clean`, `minimal` | `community/contributor-journey`, `reference/api-reference`, `release/version-policy` | badges, headers, static dividers |
| `portfolio-profile` | `portfolio-premium`, `minimal`, `creative-engineering` | `adoption/case-study`, `navigation/quick-links`, `layout/hero-sections` | headers, visuals, social buttons |

Avoid pairings where the theme tone conflicts with the repository purpose, such as high-motion demo visuals in compliance docs.
