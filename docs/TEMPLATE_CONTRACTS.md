# Template Contracts

Template contracts live under `templates/contracts/` and define the data a generator or reviewer needs before a README is considered complete.

Each contract should include required metadata, optional metadata, required sections, optional sections, recommended components, compatible themes, recommended asset categories, placeholders, defaults, quality checks, and sections to remove when irrelevant.

Contracts make templates usable by humans, the local app, and future deterministic generators without hardcoding compatibility rules in the generator.
