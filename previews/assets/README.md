# Asset previews

Generated preview indexes for the SVG asset library. Do not edit these files by hand; regenerate them with `npm run generate:previews`.

## Category index

| Category | Preview | Best for |
| --- | --- | --- |
| Badges | [`badges.md`](./badges.md) | Compact, factual status rows where a reusable visual signal is more expressive than a plain text label. |
| Banners | [`banners.md`](./banners.md) | README hero strips, project identity blocks, release announcements, and high-impact section openings. |
| Buttons | [`buttons.md`](./buttons.md) | README calls to action, install links, documentation links, sponsorship links, profile links, and status actions. |
| Callouts | [`callouts.md`](./callouts.md) | Surfacing constraints, risks, references, migration notes, and compatibility guidance inside technical documentation. |
| Cards | [`cards.md`](./cards.md) | Feature summaries, project galleries, release notes, ownership blocks, and integration overviews that work as single embeds. |
| Charts | [`charts.md`](./charts.md) | Illustrative performance, quality, capacity, allocation, readiness, and activity explanations paired with accessible text. |
| Diagrams | [`diagrams.md`](./diagrams.md) | Explaining technical relationships and flows in architecture, deployment, networking, security, data, and ML documentation. |
| Dividers | [`dividers.md`](./dividers.md) | Breaking long README pages into readable sections without adding heavy layout components. |
| File Headers | [`file_headers.md`](./file_headers.md) | Giving policy, contribution, security, support, changelog, and documentation files a polished first impression. |
| Headers | [`headers.md`](./headers.md) | Replacing plain section titles with richer visual anchors in showcase READMEs and profile pages. |
