# Code of Conduct

## Our Standard

This project is a small creative and technical toolkit. Contributors are expected to keep discussions practical, respectful, and focused on improving the repository.

Examples of constructive behavior:

- giving specific feedback about asset quality, naming, documentation, or maintainability
- explaining tradeoffs clearly
- keeping pull requests focused
- respecting licensing and attribution requirements
- helping make examples safe and easy to reuse

Unacceptable behavior includes:

- harassment, insults, or personal attacks
- dismissive or hostile review comments
- submitting assets without the right to redistribute them
- intentionally adding misleading links, unsafe SVG content, or malicious examples
- repeated off-topic disruption

## Enforcement

Maintainers may edit, hide, or remove comments and contributions that violate this code of conduct. Maintainers may also close issues or pull requests that are abusive, unsafe, or not aligned with the project.

## Reporting

Report conduct concerns privately to the repository maintainer through GitHub. Include links, screenshots, or context when useful.

## Scope

This code applies to project spaces including issues, pull requests, discussions, documentation, and any community interaction around this repository.
